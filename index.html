Fluxer to Discord Template Converter

Generate a terminal command that fetches a Fluxer server and copies the result to your clipboard, paste that into the box below, and it gets converted into Discord's real guild template. That you can use to paste into any website that imports Discord templates, including Fluxer itself. This is a Unofficial Conversion Tool. Use it at your own risk. Is not Approved by Fluxer Developers

1. Fill in your details

The auth header is always sent as Authorization, matching Fluxer's API. since thats required lmao

2. Copy the command for your terminal

Paste this into your terminal (PowerShell on Windows, Terminal on macOS, your shell of choice on Linux) and run it. The server JSON gets copied straight to your clipboard, then just paste it into the box below. On Linux you'll need the chosen clipboard tool installed, for example sudo apt install xclip. And Fair Warning, Fluxer only allows you to get JSON for what you have permissions to, so any channels you do not visually have access to inside the server you are trying to convert will not exist in the converted version.

3. Paste the fetched JSON

4. Discord template output
